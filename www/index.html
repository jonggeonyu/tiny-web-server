tiny-web-server

C 언어와 POSIX 소켓만으로 만든 웹 서버입니다. 이 페이지가 보이면 정적 파일 서빙이 동작하는 것입니다.

이 페이지가 불러온 파일

  • index.html — text/html
  • style.css — text/css (적용됨 ✔)
  • app.js — text/javascript (실행 안 됨 ✘)
  • images/logo.svg — image/svg+xml
  • images/gradient.png — image/png

링크

  • docs/ (디렉토리 → index.html)
  • docs (끝에 / 없음 → 301 리다이렉트)
  • hello.txt (한글 텍스트)
  • nope.html (404)
